## 安全与可迁移性检查

- 使用白名单复制源码、测试夹具、文档、技能、模板与种子信源；不继承原始 Git 历史。
- 没有复制个人 `.env`、cookies、历史数据库、日志、个人报告和内部协作笔记。
- 移除作者机器的绝对路径与本地 editable 依赖；通过 uv workspace 相对成员解析两个包。
- `uv.lock` 不含作者 home 的绝对路径。
- Skill 引用文档补齐，报告模板包含 frontmatter 格式修订。
- 发布内容做模式型秘密扫描；扫描不能证明不存在所有未知类型秘密，仍应正常做人工审查。
- 全部测试使用临时 HOME，清除继承的 API key/token/secret 环境变量。
