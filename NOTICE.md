# Provenance and scope

This repository consolidates the author's local newsbox 1.0.4 and news-radar-ai
1.0.0 sources. The news-radar-ai project skill includes its newer frontmatter
formatting clarification; it is newer than the installed Codex skill copy.
Original git history, private project notes, credentials, cookies, databases,
logs, virtual environments and personal reports were deliberately excluded.

The original newsbox source project is https://github.com/a809384377/newsbox .
Both components were marked MIT in their package metadata. MIT notices are
preserved in the root and component directories. Third-party dependencies
retain their own licenses. The MIT license covers project code, not content
collected from third-party sites; respect each source's terms and copyrights.

Repository integration adds an isolated runtime, guided setup, a bounded
pipeline, deterministic Markdown export, an offline demonstration and CI.
No claim is made that all external sources or model names remain available.
